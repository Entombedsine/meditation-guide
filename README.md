# Respira · Meditación para principiantes

Sitio estático (HTML + CSS + un poco de JavaScript para las animaciones, sin build) con una introducción a la meditación, pasos para empezar y videos de YouTube en español e inglés.

## Publicar en GitHub Pages

1. Sube esta carpeta a un repositorio de GitHub (rama `main`).
2. En el repositorio: **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda. En un minuto el sitio estará en `https://<tu-usuario>.github.io/<repositorio>/`.

Para verlo en local: abre `index.html` o ejecuta `python -m http.server` en esta carpeta.
